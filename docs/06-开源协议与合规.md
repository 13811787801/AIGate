# 开源协议与合规

## 本仓库

- `cmd/` `internal/` `pkg/` `web/`（自研代码）：默认 **专有许可**，用于客户私有化交付。  
- 对外开源策略未定前，勿将客户交付物默认按 AGPL 传染协议发布。

## 参考实现

| 目录 | 上游 | 协议 | 用法 |
|---|---|---|---|
| `reference/one-api` | https://github.com/songquanpeng/one-api | **MIT**（需保留署名/页脚要求按其 README） | **只读参考**；二开前需完成体检结论 |
| — | New API (Calcium-Ion/new-api) | **AGPL-3.0** | **禁止**作为闭源商用私有化默认底座 |

## 规则

1. 从 `reference/one-api` 拷贝代码进主工程时，必须在 `NOTICE` / 关于页保留 MIT 要求的署名。  
2. 不得把 AGPL 项目源码混入闭源交付包而不履行开源义务。  
3. Python 插件若引入第三方库，单独维护 `docs/licenses-plugin.md`（后期）。
