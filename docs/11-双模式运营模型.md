# AIGate · 双模式运营模型（持续经营关键）

| 项 | 内容 |
|---|---|
| 版本 | **V1.0（锁定）** |
| 日期 | 2026-09-07 |
| 效力 | **商业模式与产品分界的最高优先级决议** |

---

## 1. 一句话共识

> **私有化本地部署：Admin = 客户内部组织管理（子账户 / 用量），不卖「我们的 SaaS 套餐后台」。**  
> **走我们的 Server（网络客户端）：必须强验证，防破解——这是持续运营与收费的命脉。**

两套场景共用同一套代码，用 `deploy.mode` 分流，**绝不能混成一种 Admin**。

---

## 2. 模式对照

| | **A. 私有化 / 本地大模型** `deploy.mode=onprem` | **B. 网络客户端 → 我方 Server** `deploy.mode=saas` |
|---|---|---|
| Server 在哪 | 客户机房 / 数据中心 | **我们**托管的云端或专线 |
| 模型 | 本地 Ollama/vLLM 等为主 | 我方渠道 / 统一网关 |
| Admin 是谁 | **客户内部管理员** | **我们（厂商）运营管理员** |
| Admin 干什么 | 看本组织子账户、子客户端用量；增删本组织成员 | 分配付费套餐、开模块、停用违约账号 |
| 是否展示「SaaS 套餐编辑」 | **屏蔽**（功能由交付许可证一次性定好） | **开放**（日常运营工具） |
| 防破解重心 | 交付时许可证锁模块上限即可；日常不靠「防客户改自己服务器」赚钱 | **每次登录/会话强校验**；权限只认我方 Server |
| 收入怎么来 | 卖私有化授权 / 年费 / 实施 | 订阅、按量、套餐升级——**靠 Server 不停服与鉴权** |

---

## 3. 为什么这是「持续运营关键」

1. **若把 SaaS 套餐后台塞进私有化包**：客户会改、会越狱、会觉得「买断即可破解」，订阅收不到。  
2. **若网络客户端只靠 Electron 藏功能**：改包即可白嫖，公司无法持续。  
3. **正确分工**：  
   - 私有化：卖的是**交付授权 + 组织治理工具**（子账户用量对客户有价值）。  
   - 线上：卖的是**持续服务**，验证必须在**我方 Server**，客户端只是壳。

---

## 4. 产品行为（工程必须遵守）

### 4.1 `onprem`

- 侧栏 Admin 文案：**组织管理**（不是「套餐与用户」）。  
- 可做：子账户 CRUD、**组织角色 / 模块权限（RBAC）**、按子账户看用量、渠道与本地模型（若成员被授予 `admin_channels` 且许可证允许）。  
- 组织角色预置：`member` / `developer` / `operator` / `custom`；有效模块 = 实例∩许可证∩套餐∩组织 ACL。  
- 不可做：编辑厂商付费 SKU、对「外部付费用户」做 SaaS 分账（除非另开 saas 实例）。  
- `/api/admin/plans`：**关闭或只读**（许可证天花板）。  
- 登录后 `/api/session` 返回 `admin_surface: "org"`。  
- 渠道/模型 API 按模块能力鉴权（不要求根管理员 JWT），组织成员管理仍仅根管理员。

### 4.2 `saas`

- 侧栏 Admin：**套餐与订阅**。  
- 可做：SKU、给租户/用户开模块、停用、审计。  
- **强验证**：登录、session、敏感 API 均以我方库+许可证为准；Electron 无本地解锁。  
- `/api/session` 返回 `admin_surface: "vendor"`。  
- 生产建议 `license.require: true`。

---

## 5. Electron / 网页客户端统一约定

| 客户端连到哪 | 行为 |
|---|---|
| 客户内网 onprem Server | 组织 Admin；无厂商套餐页 |
| 我方 saas Server | 登录即拉 session；模块以服务端为准；失败则功能不可用 |

**禁止**在客户端写「本地永久解锁」。

---

## 6. 验收口径（老板级）

- [ ] onprem 控制台**看不到**「编辑付费套餐 SKU」运营台。  
- [ ] onprem 组织管理员能看到**子账户用量**。  
- [ ] saas 下免费套餐用户调未购模块 API → 403。  
- [ ] 篡改 Electron 菜单无法调用 saas 未授权 API。  

任一条不过 → **不允许对外宣称可商业化运营**。
