---

## 1. 我们达成的共识

1. **每一步都按商业化标准做**，不是“先凑合、以后再说”。  
2. **每个阶段内部**允许先用 Mock 打通链路，但阶段结束时必须达到**可演示、可售卖口径**的商业化完成度（该阶段范围内）。  
3. UI / 模型列表 / 核心流程 **对标 TokenHub**：信息架构可参考，不抄皮肤与文案。  
4. 本地 Ollama 是备选渠道；主路径是 DeepSeek / OpenAI 等云厂商。

---

## 2. 阶段门禁（Mock → 商业化）

每个 Phase 固定两道检查：

### Gate A · Mock 验收（开发中）

- 不依赖外部 Key 也能跑通本阶段主路径  
- 有 `mock` 渠道/模型或等效假数据  
- 日志、计费、权限链路可观测  

### Gate B · 商业化验收（阶段完成标准）

- 界面达到对标产品同级的**可理解性**（导航、模型列表、空状态、错误提示）  
- 真实云渠道（OpenAI 兼容）可配置、可调用（本机有 Key 时必测）  
- 无 Key 时：界面仍完整，引导用户去配置渠道，而不是“半成品空白页”  
- 文档写清：本阶段商业能力边界 / 下阶段要补什么  

**未过 Gate B，不得宣称该 Phase 完成。**
