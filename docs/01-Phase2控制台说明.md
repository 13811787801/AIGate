# Phase 2 控制台说明

## 打开地址

**http://127.0.0.1:3000/**

| 地址 | 是什么 |
|---|---|
| `/` | 控制台 UI（要登录） |
| `/healthz` | 探活 JSON |
| `/v1/...` | OpenAI 兼容 API |

## 默认登录

- 用户名：`admin`
- 密码：`admin123`（见 `configs/config.yaml`）

## 页面（对标商业信息架构）

**用户侧**

- 数据看板 / 模型广场 / 操练场  
- 令牌：名称、RPM/TPM、过期、模型白名单、IP 白名单、启停  
- 日志 / 钱包（兑换码充值）

**管理侧**

- 渠道：主流厂商下拉、启停、连通测试  
- 模型：发布、上架/下架  

## 演示兑换码

| 码 | 金额 | 说明 |
|---|---|---|
| `AIGATE-WELCOME` | ¥10 | 每用户限兑一次 |
| `AIGATE-DEMO-100` | ¥100 | 每用户限兑一次 |

## 推荐配置顺序

1. 渠道管理 → 选厂商 → 填 Key → **测试**  
2. 模型管理 → 发布对外模型并定价  
3. 令牌管理 → 创建业务 Key  
4. 钱包 → 兑换码（可选）  
5. 客户端 Base URL：`http://服务器:3000/v1`

## 启动

```powershell
cd AIGate
.\scripts\start-background.ps1
```
