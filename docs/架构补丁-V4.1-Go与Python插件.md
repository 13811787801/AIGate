## 1. 已锁定技术架构

```text
客户应用 / Cursor / SDK
        │  Bearer sk-xxx
        ▼
┌──────────────────────────────────────────┐
│           AIGate Core（Go，主进程）         │
│  鉴权 · 限流 · 计费 · 渠道路由 · 日志 · UI   │
│                                          │
│   ┌──────── Plugin Hook（可选）────────┐  │
│   │  HTTP/gRPC 调用 Python 插件进程     │  │
│   │  失败则降级：跳过插件，走默认路由    │  │
│   └────────────────────────────────────┘  │
└───────────────┬──────────────────────────┘
                │
     ┌──────────┼──────────┬─────────────────┐
     ▼          ▼          ▼                 ▼
 云厂商 API   本地模型    Redis/DB      Python Plugin（后期）
 DeepSeek    Ollama/     账本日志      选模/语义缓存/
 通义/OpenAI  vLLM/...                 本地语义分析
```

**原则：**

1. **Go 负责主路径**：没插件也能完整工作（私有化可卖）。  
2. **Python 只做增强**：选模、语义缓存、本地语义分析等；挂了不影响网关可用。  
3. **本地大模型 = 一种 Channel**，不是另一套产品。

## 2. 本地大模型（P0 设计，P1 验收）

企业常在内网跑：Ollama、vLLM、Xinference、LocalAI、One-API 兼容的自建推理服务。

| 能力 | 要求 |
|---|---|
| 接入方式 | Channel.`provider = openai_compatible`，填内网 `base_url`（如 `http://10.0.0.8:11434/v1`） |
| 鉴权 | 多数本地服务无 Key 或任意 Key；支持空 Key / 占位 Key |
| 模型映射 | 对外 `model_name` → 上游 `upstream_model`（如 `qwen2.5:14b`） |
| 计费 | 支持 **单价为 0** 或按次内部核算；分组倍率仍可用 |
| 路由 | 同一对外模型可挂「云渠道 + 本地渠道」；策略：本地优先 / 云优先 / 权重 / 仅本地 |
| 健康检查 | 探活 `GET /v1/models` 或轻量 chat；本地宕机自动摘除并切云（若配置了备用） |
| 网络 | 支持仅内网地址；文档明确「数据可不出公网」部署模式 |

**销售话术（可讲）：**  
「云模型 + 本地模型统一一把 Key；敏感业务走本地，复杂任务走云，由策略切换。」

## 3. Python 插件契约（后期，接口先预留）

### 3.1 插件何时被调用

| 插件类型 | 触发点 | 输入（摘要） | 输出（摘要） | 失败策略 |
|---|---|---|---|---|
| **ModelPicker** | 路由前 | messages、候选模型、成本/延迟约束 | 选中的 model / channel 偏好 | 用 Go 默认路由 |
| **Exact/SemanticCache** | 调上游前 | model、messages、阈值 | hit + response / miss | 当作未命中 |
| **SemanticAnalyzer** | 可选，请求前后 | text | 标签/风险分/意图 | 跳过分析 |
| **LocalEmbedder** | 语义缓存依赖 | text | embedding 向量 | 关闭语义缓存 |

### 3.2 接口形态（约定）

- 默认：**HTTP JSON**（最好排障）  
- 可选：gRPC（后期性能优化）  
- 超时：默认 50–200ms（选模/分析）；缓存查询可略高  
- 配置项：`plugin.enabled` / `plugin.base_url` / `plugin.timeout_ms` / `plugin.fail_open=true`

### 3.3 进程与部署

```text
aigate.exe          # Go 主程序（必须）
aigate-plugin.exe   # 可选：PyInstaller 打包的插件，或 python -m aigate_plugin
```

无 Docker 客户：插件也打成可执行文件；不装插件则相关菜单灰显。

## 5. 对 V4.0 的废止与替换

| V4.0 原条款 | V4.1 |
|---|---|
| Java 21 + Spring MVC 为主栈 | **改为 Go 主栈** |
| WebFlux/R2DBC 相关 | 不适用 |
| 语义缓存为独立重功能 | **改为 Python 插件能力** |
| 成功标准「Compose 一键」 | 改为：**无 Docker 可装**；Compose 可选 |
| 上游仅云厂商 | **显式包含本地 OpenAI 兼容推理服务** |

领域模型（Channel / Model / Group / ApiKey / 预扣计费）**不变**。

## 6. 排障补充（本地模型 / 插件）

1. 本地模型失败 → 先 `curl http://本地IP:端口/v1/models`  
2. 渠道 Base URL 是否少了 `/v1`  
3. 是否配置了云备用；无备用则本地挂即全挂  
4. 插件超时/5xx → 看 Go 日志是否 `fail_open` 降级成功  
5. 语义缓存异常 → 关掉插件开关，确认主链路恢复
