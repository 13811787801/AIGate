# Go 开发避坑与排障速查（AIGate 实用向）

> 副产品文档：方便你 **debug**，不是系统学 Go。  
> 遇到报错：先在本文搜关键词，再把完整报错贴给协助开发的人。

---

## 1. 排障总顺序（先做这个）

1. **命令在不在**：`go version` / `where.exe go`  
2. **是不是在项目根目录**：必须在 `E:\Projects\AIGate`  
3. **配置在不在**：有没有 `configs\config.yaml`  
4. **端口占没占**：`netstat -ano | findstr :3000`  
5. **看程序日志**：终端里红色/最后几行  
6. **接口通不通**：`Invoke-RestMethod http://127.0.0.1:3000/healthz`

## 2. 环境类常见错误

### 2.1 `go : 无法识别...`

**原因**：没装 Go，或装了没重开终端，或 PATH 没有 `Go\bin`。

**处理**：按 [03-Go环境安装与使用手册](./03-Go环境安装与使用手册.md) 重装/重开终端。

### 2.2 `package xxx is not in GOROOT`

**原因**：在错误目录执行，或模块名/路径不一致。

**处理**：

```powershell
cd E:\Projects\AIGate
go list -m
# 应显示：aigate
```

### 2.3 `missing go.sum entry` / 下载依赖失败

**处理**：

```powershell
go env -w GOPROXY=https://goproxy.cn,direct
go mod tidy
```

### 2.4 同时存在两个 Go，行为诡异

```powershell
where.exe go
```

只保留一个正式安装；开发脚本已优先用 PATH 中的 `go`。

### 2.6 `version "go1.xx" does not match go tool version "go1.yy"`

**原因**：系统装了新 Go，但环境变量 `GOROOT` 仍指向旧便携目录。

```powershell
Remove-Item Env:GOROOT -ErrorAction SilentlyContinue
# 或新开终端（不要手动 set GOROOT）
go env GOROOT
# 应类似：C:\Program Files\Go
```

**原因**：Go 安装树若放在 module 根下（例如曾经的 `AIGate\tools\go`），会被当成项目代码扫描。

**处理**：工具链必须在模块外，例如 `E:\Projects\.toolchain\go`。  
**永远不要**把官方 Go 源码目录放进 `E:\Projects\AIGate` 里。

## 3. 运行 / 编译类

### 3.1 `listen tcp :3000: bind ... only one usage`

端口被占用（可能上次 `aigate.exe` 没关）。

```powershell
# 查谁占用 3000
netstat -ano | findstr :3000
# 结束对应 PID（任务管理器或）
Stop-Process -Id <PID> -Force
```

或改 `configs\config.yaml` 里 `server.port`。

### 3.2 `load config failed`

```powershell
Copy-Item configs\config.example.yaml configs\config.yaml
```

### 3.3 改了代码没变化

你跑的是旧的 `dist\aigate.exe`。  
开发请用 `.\scripts\dev-run.ps1`（`go run`），或重新 `build-windows.ps1`。

### 3.4 `501 not implemented`（`/v1/chat/completions`）

Phase 0 **正常现象**，不是环境坏了。Phase 1 才会接通上游。

## 4. 读报错的方法（Go 风格）

Go 报错通常长这样：

```text
.\internal\server\server.go:41:2: undefined: trace.Ensure
```

解读：

| 段 | 意思 |
|---|---|
| `文件:行:列` | 出错位置，Cursor 里 Ctrl+点击可跳转 |
| `undefined: Xxx` | 用了没定义的名字 / 包没导入 |
| `declared and not used` | 变量导入了没用（Go **比 Java 严**，禁止无用） |
| `cannot use A as B` | 类型不匹配 |

**把从第一行 `error`/`FAIL` 到最后的完整文本复制出来**，比只说“跑不起来”有用 10 倍。

## 5. 语法 / 语义速查（够用即可）

### 5.1 和 Java 的直觉对照

| Java | Go |
|---|---|
| `package com.x;` | `package server`（目录名常一致） |
| `import com.x.Y` | `import "aigate/internal/config"` |
| `public class App` | 无 class 强制；`func main()` 入口 |
| `null` | `nil` |
| 异常 try/catch | 多返回值 `result, err := ...`；**自己判断 err** |
| 接口 implements | 隐式实现：方法集对上即实现接口 |
| 文件名随便 | 同目录必须同 `package` 名 |

### 5.2 最常见语法点

```go
// 短变量声明（只能在函数内）
cfg, err := config.Load(path)
if err != nil {
    return err
}

// 导出规则：首字母大写 = 包外可见（类似 public）
func Run(cfg *config.Config) error { ... }  // 可被 main 调用
func writeJSON(...) { ... }                 // 包内私有

// 指针：常用于结构体，避免大拷贝
func Load(path string) (*Config, error)

// 零值：数字0、字符串""、指针nil，一般不必写 new
```

### 5.3 务必记住的语义坑

1. **`err` 必须处理**（或显式 `_ =` 丢掉，但不推荐）。  
2. **没用的 import / 变量直接编译失败**（不是警告）。  
3. **`:=` 与 `=`**：`:=` 声明并赋值；`=` 只赋值。  
4. **切片 / map 传的是引用味道**，别当 Java 小白以为一切是值拷贝就乱改。  
5. **goroutine**：`go func(){}()` 异步；Phase 1 前你先当“别乱开线程”。

## 6. AIGate 项目里怎么定位代码

```text
请求进来
  cmd/aigate/main.go          → 读配置、启动
  internal/config             → 配置结构
  internal/server             → HTTP 路由（/healthz /v1/...）
  internal/auth（Phase1）     → 鉴权
  internal/channel（Phase1）  → 上游/本地模型
  internal/billing（Phase1）  → 计费
  internal/plugin             → Python 插件（后期，可关）
```

改接口行为 → 先看 `internal/server`。  
改端口/密码 → 先看 `configs/config.yaml`。
