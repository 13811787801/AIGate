## 1. 产品一句话

> **AIGate-Pro = 可私有化部署的 OpenAI 兼容企业 AI API 网关 + 配额治理控制台。**  
> 企业把云厂商 Key / 本地大模型接到网关，对内用一把 `sk-` + 统一 Base URL 调用；可选连我方托管 Server 做订阅制强校验。

**不是：** 聊天站、Token 倒卖站、必须 Docker 才能跑的重平台、Electron 单独业务后端。

## 3. 应用场景

### 3.1 场景 A · 企业机房私有化 + 本地/混合模型（主场景）

| 项 | 描述 |
|---|---|
| 部署 | `deploy.mode=onprem`；Server 在客户数据中心 |
| 模型 | 本地 Ollama/vLLM 等（`openai_compatible`）± 可选云渠道 |
| 用户 | 企业内部员工/系统；组织管理员管本组织 |
| Admin | **组织管理**：子账户、用量；**无**厂商套餐编辑台 |
| 收费逻辑 | 卖私有化授权/年费/实施；功能上限由交付许可证锁定 |
| 客户端 | 浏览器控制台；后期 Electron 连内网 Server |

### 3.2 场景 B · 网络客户端连我方 Server（订阅运营）

| 项 | 描述 |
|---|---|
| 部署 | `deploy.mode=saas`；Server **我们**托管 |
| 用户 | 付费租户/终端用户 |
| Admin | **厂商运营**：套餐 SKU、分配模块、停用账号 |
| 防破解 | 每次登录/session/API **服务端强校验**；改 Electron 无效 |
| 收费逻辑 | 订阅/按量；**持续运营命脉在 Server 鉴权** |

### 3.3 场景 C · 业务系统接入（两种部署共用）

业务侧（Cursor / 自研 / SDK）只配置：

- Base URL：`http(s)://<网关>/v1`  
- API Key：`sk-...`  

无需感知 onprem/saas 差异（差异在账号权益，不在协议）。

## 4. 角色与权限矩阵

| 角色 | 标识 | 能力摘要 | 边界 |
|---|---|---|---|
| **系统/组织管理员** | `role=admin` 或配置管理员用户名 | 渠道、模型、组织子账户（onprem）或套餐用户（saas）、总览 | 不能越过实例许可证天花板 |
| **普通用户** | `role=user` | 令牌、日志、钱包（若模块开）、操练场/广场（若模块开）、本账户调用 | 不能访问管理 API；模块外 API→403 |
| **子账户** | `parent_id=组织管理员` | 同普通用户；归属组织 | onprem 下仅父账号可启停 |
| **业务调用方** | API Key | `/v1/*` 调用 | 受 Key 白名单/过期/余额/分组模型约束 |
| **厂商签发方** | 持有 license 私钥 | 签发 `license.json` | 私钥永不进客户包 |

### 4.1 有效权益计算公式（冻结）

```text
有效模块 = 实例 modules.*  ∩  许可证 modules（若有）  ∩  用户套餐 plan.modules
管理员   = 实例上限（仍受许可证约束）
core / console 恒为 true
```

服务端每次敏感 API 调用 `requireModuleFor`；**客户端菜单仅为展示**。

### 4.2 `admin_surface`（冻结）

| `deploy.mode` | `admin_surface` | 控制台入口文案 |
|---|---|---|
| `onprem` | `org` | 组织管理 |
| `saas` | `vendor` | 套餐与订阅 |
