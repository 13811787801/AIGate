# Go 环境安装与使用手册（Windows · 白丁版）

> 面向：几乎没写过 Go、但要能在本机跑 / 编译 / 排查 AIGate 的人。  
> 目标：本机 `go` 命令稳定可用，开发与交付不靠“临时解压碰运气”。

---

## 0. 先回答你的问题

### winget 可以再装一次吗？

**可以，而且推荐再装一次（系统级安装）。**

| 方式 | 适合你吗 | 说明 |
|---|---|---|
| **winget / 官方 MSI** | ✅ **首选** | 装到 `C:\Program Files\Go`，写入 PATH，环境“正规” |
| 便携 ZIP（我们临时用过） | 备用 | 在 `E:\Projects\.toolchain\go`，不进系统 PATH 时容易晕 |
| 自己乱下绿色版到处拷 | ❌ | 容易多份 Go 互相打架 |

上次 winget 失败是因为安装程序被取消（退出码 1602，常见于 UAC 弹窗点了“否”）。  
**再装时：弹出“是否允许此应用修改设备”请点「是」。**

### 要不要手动安装？

- winget 能成功 → **不用手动**  
- winget 再失败 → 用官网 MSI 手动装（下文 §2.2），一样正规  

**结论：优先 winget；失败再用 MSI。装好后以系统 Go 为准，便携版仅作备用。**

## 1. 安装前检查

打开 **新的** PowerShell：

```powershell
go version
where.exe go
```

| 结果 | 含义 |
|---|---|
| 有版本号，路径在 `C:\Program Files\Go\bin\go.exe` | 已装好，跳到 §3 |
| 提示不是内部命令 | 未装或 PATH 未生效 → 继续安装 |
| 有版本但路径在 `.toolchain` | 临时环境，仍建议装系统版 |

## 2. 安装步骤

### 2.1 方式 A：winget（推荐）

1. **以普通用户打开 PowerShell**（或终端）。  
2. 执行：

```powershell
winget install --id GoLang.Go -e --accept-source-agreements --accept-package-agreements
```

3. 若弹出 UAC → **允许**。  
4. **关掉所有终端窗口，再新开一个**（PATH 只对新建会话生效）。  
5. 验证：

```powershell
go version
where.exe go
# 期望类似：
# go version go1.22.x windows/amd64   （或 1.23 / 1.24 / 1.27 均可，≥1.22）
# C:\Program Files\Go\bin\go.exe
```

### 2.2 方式 B：官网 MSI（winget 失败时）

1. 浏览器打开：https://go.dev/dl/  
2. 下载 **Windows** → **msi**（amd64）。  
3. 双击安装，勾选加入 PATH（默认一般已勾选）。  
4. 装完 **重开终端**，再执行 `go version`。

### 2.4 装完后若编译报 `version does not match go tool`

常见原因：终端里还留着旧的 `GOROOT`（例如指向便携 1.22）。

```powershell
# 查看
go env GOROOT
# 若不是 C:\Program Files\Go ，在当前窗口清除后重试：
Remove-Item Env:GOROOT -ErrorAction SilentlyContinue
go env GOROOT
go version
```

然后**新开一个终端**再编译。本项目脚本已避免强行设置错误 GOROOT。

```powershell
# 1) 版本
go version

# 2) 环境（看 GOROOT / GOPATH）
go env GOROOT
go env GOPATH
go env GOPROXY

# 3) 国内若下载模块慢，可设代理（可选，二选一）
go env -w GOPROXY=https://goproxy.cn,direct
# 或
go env -w GOPROXY=https://proxy.golang.com.cn,direct
```

常见含义：

| 变量 | 是什么 | 你要关心吗 |
|---|---|---|
| `GOROOT` | Go 自己装在哪 | 一般别手改 |
| `GOPATH` | 你的模块缓存/工作区，默认 `%USERPROFILE%\go` | 知道即可 |
| `GOPROXY` | 下载依赖的镜像 | 下载失败时改这个 |

## 4. 每天开发会用到的最少命令

在 `E:\Projects\AIGate` 下：

| 命令 | 干什么 |
|---|---|
| `go run .\cmd\aigate -c configs\config.yaml` | 边改边跑（开发） |
| `go build -o dist\aigate.exe .\cmd\aigate` | 编译 exe |
| `go test .\...` | 跑测试（Phase 1 起会有） |
| `go mod tidy` | 根据 import 整理依赖 |
| `go env` | 看环境是否正常 |

**记忆口诀：**  
改代码 → `dev-run` → 浏览器/接口验证 → 出包用 `build-windows`。

## 5. 推荐的编辑器用法（Cursor / VS Code）

1. 用 Cursor **打开文件夹** `E:\Projects\AIGate`（不要只开单个文件）。  
2. 安装扩展：**Go**（官方 `golang.go`）。  
3. 扩展会提示安装 `gopls` 等工具 → 点安装。  
4. 若提示 `go` not found：说明终端 PATH 还有问题，重开 Cursor。

## 6. 卸载 / 多版本打架时怎么处理

若 `where.exe go` 出现**多行**路径：

```powershell
where.exe go
```

保留 `C:\Program Files\Go\bin\go.exe`，其余临时目录可删或移出 PATH。

卸载系统 Go：  
「设置 → 应用 → 已安装的应用 → Go Programming Language → 卸载」，再重装一次即可。

便携备用目录（可不删）：`E:\Projects\.toolchain\go`
